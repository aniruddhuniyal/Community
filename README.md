# community

A small corner for people who build things and want to talk about it.
Share what you're working on, ask questions, argue about tools.

Run by [Aniruddh Uniyal](https://github.com/aniruddhuniyal).

---

## How this repo is laid out

Each branch does one job, so check out the one you need.

| Branch | What it's for |
| --- | --- |
| `master` | This README, the rules, and everything that holds the repo together |
| `discussions` | Open conversations, questions, ideas, and feedback |
| `top-10` | Ranked list of top 10 ideas from the community |

```bash
git checkout discussions
```

---

## Joining in

**Discussions**
Add a new file in `discussions/` named after your topic, or reply under an existing one. Keep it readable. Nobody wants to scroll through a wall of text.

**Top 10**
Got a list worth ranking? Open a PR against `top-10` with your entry. If it's ranked, give a one-line reason for each pick. "It's good" doesn't count.

---

## Ground rules

- Be decent. Disagree with ideas, not people.
- No spam, no self-promo dumps. Sharing your own work is fine, just not only that.
- If you're unsure where something goes, open an issue and ask.

---

## Contributing

1. Fork the repo
2. Branch off the one you're contributing to
3. Make your change
4. Open a PR with a short description of what and why

That's it.
